# The Quiet Oracle

A professional tarot reading table with the restraint of an engraved print. Ivory paper, antique gold, forest-green cards and dark ink support expressive photographic imagery.

- Paper `#f4f1e8`, ink `#2b302c`, gold `#7d6538`, forest `#263d33`, muted `#66695d`, hairline `#d8d3c3`.
- Cormorant Garamond for identity and large editorial typography. DM Sans for functional UI and quiet instructions.
- Desktop has a calm left introduction and a right card table. Mobile centers the reading, removing secondary explanatory copy.
- The card back is original SVG engraving: a human-faced sun, crescent moon, eye, radiating strokes and botanical corners. A faint celestial dial grounds the table.
- Faces and photographic expressions supply the symbolism. Cards have no assigned titles, joke captions or generated interpretations. Contain-fit imagery preserves the source photograph.
- Draw uses a forest-green button. Shuffle and Clear are supporting actions. Card reveals use physical dealing and a 3D turn; reduced motion skips animation.
- Every interface string, metadata description and image alt description is English. The collection dialog preserves Pinterest provenance.

## Motion and interaction

Use physical card motion in response to an action. The main card has separate backfaces in a preserved 3D space; each draw slides engraved backs from a dealer’s deck onto the table one at a time. Three- and five-card readings form a row before gathering into a visible fanned hand; a single card moves into place, lifts and turns. Opening the hand staggers its photographic cards; Next reading gathers the hand before the table returns to rest. Shuffle splits the layers of the underlying deck.

The palette and original artwork remain authoritative. Controls are grouped into a compact reading panel, with the active hand becoming the primary action after a draw. Mobile uses a shorter introduction and smaller resting deck to keep the table and action within reach. Hover tilt is limited to fine pointers. Reduced motion and background tabs finish or bypass visual effects; they never delay saving the reading.
