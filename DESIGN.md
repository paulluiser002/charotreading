# The Quiet Oracle

A professional tarot reading table with the restraint of an engraved print. Ivory paper, antique gold, forest-green cards and dark ink support expressive photographic imagery.

- Paper `#f4f1e8`, ink `#2b302c`, gold `#7d6538`, forest `#263d33`, muted `#66695d`, hairline `#d8d3c3`.
- Cormorant Garamond for identity and large editorial typography. DM Sans for functional UI and quiet instructions.
- Desktop has a calm left introduction and a right card table. Mobile centers the reading, removing secondary explanatory copy.
- The card back is original SVG engraving: a human-faced sun, crescent moon, eye, radiating strokes and botanical corners. A faint celestial dial grounds the table.
- Faces and photographic expressions supply the symbolism. Cards have no assigned titles, joke captions or generated interpretations. Contain-fit imagery preserves the source photograph.
- Draw uses a forest-green button. Shuffle and Clear are supporting actions. Card reveal uses a restrained fade and turn; reduced-motion skips animation.
- Every interface string, metadata description and image alt description is English. The collection dialog preserves Pinterest provenance.
